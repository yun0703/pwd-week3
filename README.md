# TypeScript 계산기 프로젝트 (PWD-Week3)

본 프로젝트는 TypeScript와 HTML/CSS를 활용하여 구현한 웹 기반 계산기 애플리케이션입니다. 사용자 입력 처리, 계산 상태 관리, 사칙연산 로직이 각 모듈별로 분리되어 구조화되어 있습니다.

---

## 프로젝트 실행 방법

아래 순서대로 명령어를 실행하여 프로젝트를 빌드하고 실행할 수 있습니다.

### 1. 의존성 패키지 설치
프로젝트에 필요한 패키지들을 설치합니다.
```bash
npm install
```

### 2. TypeScript 프로젝트 빌드
TypeScript 소스 코드를 JavaScript 파일로 컴파일합니다.
```bash
npm run build
```
> 빌드가 완료되면 컴파일된 JavaScript 파일이 `./js/` 폴더 내에 생성됩니다.

### 3. 결과 확인
- 프로젝트 루트 폴더의 `index.html` 파일을 브라우저로 엽니다.
- 또는 VS Code의 **Live Server** 확장을 사용하여 실행합니다.

## Step 7 실습 관찰 결과 및 코드 분석

### 1. 시나리오별 관찰 결과

| 입력 순서 | 화면 및 동작 관찰 결과 |
| :--- | :--- |
| **`AC` → `1` → `2` → `+`** | 상단 디스플레이에 `12 +`가 표시됨을 확인. |
| **`3` 입력** | 디스플레이 표시가 `12 + 3`으로 업데이트됨을 확인. |
| **`=` 입력** | 상단에 `12 + 3 =`이 표시되고, 결과 값으로 `15`가 출력됨을 확인. |
| **숫자 `7` 입력** | 이전 계산식이 자동으로 지워지고 `7`로 새로운 입력이 시작됨을 확인. |
| **`AC` 입력** | 전체 입력 상태 및 계산식이 초기화되고 `0`으로 돌아감을 확인. |

---

### 2. 해당 동작을 담당하는 파일 및 함수 분석

- **UI 및 이벤트 처리 (`app.ts`)**
  - **역할:** DOM 요소 선택, 버튼 클릭 이벤트 리스너 등록, 화면 업데이트 담당.
  - **주요 함수/메서드:** `initEvents()` (버튼 이벤트 바인딩), `updateDisplay()` (화면 출력 갱신)

- **계산기 상태 관리 및 흐름 제어 (`calculator.ts`)**
  - **역할:** 숫자 및 연산자 입력 상태 관리, 계산 완료 후 새 입력 시작 처리, AC 초기화 로직 수행.
  - **주요 함수/메서드:** `inputNumber()`, `setOperator()`, `calculate()`, `clear()`

- **사칙연산 로직 (`operations.ts`)**
  - **역할:** 전달받은 두 숫자에 대해 실제 덧셈, 뺄셈, 곱셈, 나눗셈 수학 연산을 수행하여 결과 반환.
  - **주요 함수/메서드:** `add()`, `subtract()`, `multiply()`, `divide()`
